# 🌟 Marca Personal Groovy - Karla Sofía Mosquera Mejía

Sitio web portafolio dinámico e interactivo diseñado para **Karla Sofía Mosquera Mejía**, Comunicadora Social - Periodista. El proyecto destaca por una estética retro **70s Groovy**, utilizando tonos naranja vibrante, amarillo sol, crema y detalles borgoña, combinados con tipografías icónicas y animaciones interactivas.

---

## 🎨 Características & Diseño

* **Estilo Visual:** Retro 70s / Groovy Chic con sombras sólidas (*groovy-shadow*), formas orgánicas y paleta de colores cálidos.
* **Tipografías:**
  * Header/Títulos: `Shrikhand` (Google Fonts).
  * Cuerpo de texto: `Plus Jakarta Sans`.
* **Filtro de Portafolio:** Categorización dinámica por Periodismo Digital, Realización Audiovisual, Opinión & Crítica y Teatro & Arte.
* **Secciones Integradas:**
  * **Hero Section:** Presentación con enlaces rápidos al portafolio de Canva, redes sociales y descarga/resumen de HV.
  * **Perfil Profesional:** Síntesis narrativa y estadísticas destacadas.
  * **Trayectoria:** *Timeline* interactivo de experiencias (El Giro UAO, El Gamín Pensante, Revista Vía Pública, COP16, La Sucursal Broadway).
  * **Formación Académica:** Tarjetas informativas de pregrado y diplomados.
  * **Habilidades & Software:** Clasificación de herramientas (DaVinci Resolve, Photoshop, Adobe Suite, WordPress, Pro Tools, etc.).
  * **Contacto:** Formulario dinámico y datos directos de WhatsApp/Correo.
* **Diseño Responsive:** Totalmente adaptado para dispositivos móviles, tablets y pantallas de escritorio.

## 🚀 Despliegue en Producción

El sitio está desarrollado bajo una arquitectura de **archivo único optimizado**, lo que permite un despliegue directo en cualquier servicio de hosting estático o servidor web:

### Opción 1: GitHub Pages
1. Crea un repositorio en GitHub (ej. `karla-mosquera-web`).
2. Sube los archivos `index.html`, `README.md` y tus imágenes asociadas.
3. Ve a `Settings` > `Pages`.
4. En **Branch**, selecciona `main` y la carpeta `/root`. Haz clic en **Save**.

### Opción 2: Vercel / Netlify
1. Conecta tu cuenta de GitHub/GitLab con Vercel o Netlify.
2. Selecciona el repositorio de la página.
3. Deja la configuración de Build por defecto (sitio estático).
4. El despliegue se realiza automáticamente en segundos.

### Opción 3: Hosting Tradicional (cPanel / FTP)
* Sube los archivos directamente a la carpeta pública (`public_html` o `www`) a través de un cliente FTP (FileZilla) o el Administrador de Archivos.

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Marcado semántico y accesible.
* **Tailwind CSS (v3 CDN):** Framework de CSS orientada a clases de utilidad para estilos rápidos y responsivos.
* **FontAwesome 6:** Iconografía vectorial.
* **Google Fonts:** Fuentes `Shrikhand` y `Plus Jakarta Sans`.
* **JavaScript Plain (ES6+):** Lógica para modales, filtros de proyectos, menú hamburguesa y manejo del formulario de contacto.
